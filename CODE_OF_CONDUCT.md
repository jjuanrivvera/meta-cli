# Code of conduct

## Our standards

Contributors are expected to make participation respectful, welcoming, and constructive. Examples
include showing empathy, accepting feedback, focusing on what is best for the community, and using
inclusive language.

Harassment, personal attacks, discrimination, publishing private information, and other conduct
that would reasonably be considered inappropriate are not acceptable.

## Enforcement

Report unacceptable behavior privately through the repository owner's GitHub profile. Reports will
be reviewed promptly and handled with respect for the privacy and safety of everyone involved.

Project maintainers may remove, edit, or reject contributions and may temporarily or permanently
exclude participants whose behavior violates these standards.
